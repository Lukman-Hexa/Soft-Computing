## 🚀 Cara Penggunaan

**1. Instal dependensi Python:**
   
   pip install flask numpy
   
**2. Jalankan server Python:**
   
   python app.py
   
   [http://localhost:5000](http://localhost:5000)

**3. Gunakan tab untuk beralih antar kasus:**

   - **Tab PSO - Optimasi Produksi**  
     Isi parameter dan klik **"Jalankan Optimasi PSO"**

   - **Tab Bayesian - Diagnosis Penyakit**  
     Pilih profil pasien dan gejala, lalu klik **"Hitung Probabilitas"**

   - **Tab Markov - Prediksi Kredit**  
     Masukkan jumlah bulan dan distribusi awal, lalu klik **"Prediksi Status Kredit"**
